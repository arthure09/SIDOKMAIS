# Isi folder `docs/`

## Yang masuk repo

| File | Isi |
|---|---|
| `testing-manual.md` | Checklist testing manual per modul aplikasi |
| `keputusan-tertunda.md` | Keputusan desain yang sengaja ditunda — alasan, pemicu, dan syarat lanjut |

## Catatan lokal — tidak masuk repo

Beberapa dokumen kerja pribadi (jurnal harian, laporan, catatan belajar, draft
rencana yang sudah tidak akurat terhadap implementasi aktual) sengaja
dikeluarkan dari repo lewat `.gitignore`. Isinya tetap ada di disk masing-masing
kontributor, cuma tidak ikut ke-share lewat git.

## Aturan singkat menaruh dokumen baru

- Dokumen yang berlaku terus dan relevan buat siapa pun yang melanjutkan
  project ini (arsitektur, keputusan desain, panduan testing) → masuk `docs/`
  dan ikut repo.
- Catatan kerja pribadi/sekali pakai (jurnal, laporan progres, draft rencana
  sebelum implementasi) → tetap taruh di `docs/` untuk kenyamanan lokal, tapi
  daftarkan di `.gitignore` supaya tidak ikut ke repo.
